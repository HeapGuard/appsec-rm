# КОНТУР // APPSEC

Локальная персональная консоль для годового пути к Junior AppSec Engineer. Это статическое React-приложение: roadmap, статусы знаний, ежедневный журнал, календарь активности, простое spaced repetition, отчёты и резервное копирование работают в браузере без аккаунта и backend.

_Здесь можно разместить скриншоты Пульта, Маршрута и ежедневного журнала после запуска проекта._

## Технологии

- Vite, React, TypeScript (strict)
- Обычный CSS без UI-библиотек
- localStorage для пользовательских данных

## Локальный запуск

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Результат находится в `dist/` и готов для статического деплоя на Vercel. Переменные окружения и серверный fallback не требуются: навигация реализована в клиентском интерфейсе без URL-роутинга.

## Данные curriculum

Roadmap, темы и библиотека материалов лежат в [src/data/curriculum.ts](src/data/curriculum.ts). Пользовательский прогресс никогда не смешивается с curriculum: он хранится отдельно под ключом `appsec-console-state-v1`.

### Добавить тему

Добавь запись в нужный массив `seeds` в `curriculum.ts` и при необходимости задай для неё вопросы в `sharedQuestions`. ID темы должен быть уникальным. Он автоматически появится в теме этапа, поиске и журнале.

### Добавить материал

Добавь запись в массив `resources`: `id`, `title`, `type`, `language`, `url`, `description`, `relatedTopicIds`. Используй существующий ID связанной темы.

## Backup

Открой «Данные» → «Экспорт JSON». Скачается полный backup с прогрессом, заметками, журналом и повторениями. Там же можно импортировать валидный JSON обратно. В приложении есть мягкое напоминание, если экспорт не выполнялся более 30 дней.
